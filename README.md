# Ecommerce Website

A responsive ecommerce website built while learning HTML, CSS, and JavaScript.

This project is based on the **Build and Deploy Ecommerce Website Using HTML CSS JavaScript** tutorial by Tech2etc.

## Technologies

* HTML5
* CSS3
* JavaScript

## Features

* Responsive website layout
* Navigation bar
* Homepage
* Product listing
* Product details
* Shopping cart interface
* Responsive design for different screen sizes

## Project Status

Currently in development.

This project is being built progressively while following the tutorial and adding my own improvements and experiments.

## What I'm Learning

Through this project, I'm practicing:

* HTML page structure
* CSS layouts and responsive design
* Flexbox
* Media queries
* JavaScript
* DOM manipulation
* Git and GitHub
* Website deployment
